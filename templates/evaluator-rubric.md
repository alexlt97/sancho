# Evaluator rubric

Score each completed feature A–D. A feature is acceptable only when every dimension is B or above.

| Dimension | A | B | C | D |
| --- | --- | --- | --- | --- |
| Correctness | Behavior and edge cases verified | Main behavior verified | Partial verification | Broken or unverified |
| Architecture | Boundaries and constraints enforced | No known boundary violations | Minor drift | Violates a core boundary |
| Tests | Deterministic and device evidence where needed | Relevant tests pass | Weak coverage | Missing or failing tests |
| Verification evidence | All required layers recorded | Required checks recorded | Some checks missing | No credible evidence |
